# 心理实验室 · Psy Lab

一个**开源、纯前端、零依赖、注重隐私**的心理与性格测评网站。iOS 27 Liquid Glass 风格界面，通过 GitHub Actions 自动构建并部署到 GitHub Pages。

> 没有后端，没有追踪，所有答案和日记只保存在你自己的浏览器里。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库，把本项目推送到 `main` 分支：
   ```bash
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
2. 打开仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
3. 推送后 Actions 会自动运行 `.github/workflows/deploy.yml`：校验题库 → 构建到 `dist/` → 部署。
4. 访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

所有路径都是相对路径，部署在子目录下也能正常工作。

## 本地开发

只需要 Node.js 18+，无需安装任何依赖：

```bash
npm run dev       # 预览 src/，http://localhost:5173
npm run build     # 校验题库并构建到 dist/
npm run preview   # 构建后预览 dist/，http://localhost:4173
```

> ⚠️ 由于使用了 ES Modules，不能直接双击 `index.html` 用 `file://` 打开，请使用上面的本地服务器。

## 添加一个新测评

在 `src/js/tests/` 新建文件，导出如下结构，然后在 `tests/index.js` 中注册：

```js
import { AGREE5, dimMeans, pct5 } from './common.js';

export default {
  id: 'grit',                 // 唯一 id，也用于 URL
  name: '坚毅量表', short: '坚毅', icon: 'mountain', tint: '#ff9500',  // icon 取自 icons.js
  category: 'growth',         // personality | relationship | growth | career | mood
  minutes: 3, shareable: true, // sensitive: true 会显示温馨提示且禁用结果链接
  intro: '……', prompt: '这句话在多大程度上符合你？', reference: '出处……',
  scale: AGREE5, scaleStyle: 'agree',   // 'agree' 横向圆点，'list' 纵向选项
  items: [{ t: '题目', k: '维度', r: 1 /* 反向计分 */ }],
  score(answers) {
    return { headline, title, icon, summary, line, viz: [...], sections: [...] };
  },
};
```

`npm run build` 会自动用最小/最大/中间/随机答案跑一遍计分，并检查所有图标名是否存在、源码里有没有 emoji。
